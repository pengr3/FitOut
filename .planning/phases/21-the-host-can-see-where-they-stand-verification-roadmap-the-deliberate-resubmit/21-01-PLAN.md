## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-21-01 | Spoofing | readiness receipt | high | mitigate | Invoke the imported `deriveBookable` per listing and mutation-test the XOR receipt; never infer readiness from card states. |
| T-21-02 | Tampering | stale/retry eligibility | high | mitigate | Share the exact cooldown/grace declarations, compare against the page's DB clock, and leave guarded Server Actions authoritative. |

| T-21-04 | Denial of Service | dashboard composition | medium | mitigate | Replace the existing listing count projection and reuse every other read; tests pin zero added query round trips and no render-loop query. |
| T-21-05 | Elevation of Privilege | roadmap mutations | high | mitigate | Reuse shipped Server Actions whose first boundary independently authenticates/authorizes per the installed Next.js 16 Forms guide. |
| T-21-01-SC | Tampering | package installs | high | mitigate | Install no package; manifests, lockfile, registries, and shared primitives remain unchanged. |
</threat_model>
