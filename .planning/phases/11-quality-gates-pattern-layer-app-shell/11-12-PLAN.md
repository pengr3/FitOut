<objective>
Move the ambient notification read behind a streaming boundary and put the booker and host headers on
`site-chrome` — without moving a security gate.

Purpose: both group layouts `await` three database reads before rendering, and Next's documented behaviour
is that a layout awaiting runtime data blocks navigation. Until that moves, a `loading.tsx` under either
group buys nothing. This is also **the single riskiest edit in the phase**: a `redirect()` behind
`<Suspense>` streams the gated shell before the redirect resolves.
Output: two restructured layouts, one async child, and a gate over the blocking property.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| unauthenticated request → gated layout | The `redirect()` is the only thing between an anonymous request and booker/host markup |
| request-supplied identifiers → notification query | An id from anywhere but the verified session is an IDOR |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-06 / T-04-02 | Elevation of Privilege | `(app)` and `(host)` session and capability gates | mitigate | `getSession` + both `redirect()` calls stay blocking; asserted structurally by an AST gate that walks JSX ancestors (not source order) and behaviourally by three shipped e2e specs; a signed-out `curl` must return no gated markup |
| T-07-82 | Elevation of Privilege | notification reads | mitigate | Owner-scoping stays **in the query** on `session.user.id`, passed as a prop from the blocking parent; the child never re-reads the session and never accepts a request-supplied id — asserted by a zero-count grep for `getSession`/`headers()` in the child |
| T-11-CLOCK | Tampering | relative notification labels | mitigate | `readDbNow(db)` retained in the streamed triple; a skewed client clock would otherwise render "in 3 hours" on a just-arrived notification |
| T-11-SHELLDOWN | Denial of Service | the layout carrying the session gate | mitigate | The try/catch degradation to `notificationsFailed` survives the move — an ambient read must never take down the shell |
| T-11-TOASTDUP | Repudiation | Toaster mount | mitigate | Exactly one `<Toaster` across `src/app/**`, asserted by a count |
| T-11-SC | Tampering | npm | mitigate | Zero packages |
</threat_model>
