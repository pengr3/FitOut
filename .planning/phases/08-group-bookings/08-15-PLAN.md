<objective>
Close **CR-01 (BLOCKER)** — the pax surcharge makes every surcharged hourly booking render **"Full day"** on eighteen surfaces.

`quoteWindow` returns `totalCents = baseCents + surchargeCents` (`src/lib/booking/pricing.ts:128`) and `createPendingHold` freezes that into `spacePriceCents` (`src/lib/availability/units.ts:511`). The shared formatter then re-derives the mode by *inequality*: `fullDay = hourlyTotal == null || spaceCents !== hourlyTotal` (`src/lib/booking/when-label.ts:67`). For an hourly booking with `extraHeadFee > 0` and `declaredPax > included`, `spaceCents` is `hourlyRate × hours + surcharge`, which by construction is not equal to `hourlyRate × hours` — so the formatter concludes "Full day" and prints it instead of `8:00 AM – 10:00 AM`.

`08-05` identified this exact hazard and fixed it *by formatting inline* on two page files (`src/app/listings/[id]/book/page.tsx:170` and `src/app/(app)/bookings/[id]/page.tsx:241`), leaving grep tripwires behind. It did not fix the shared module that every **email**, every **notification payload**, the **public invite page**, the **organizer management page**, the **cancel review screen**, `/bookings`, `/host/bookings`, `/host/requests`, the reminders, the request-expiry mail and the payment webhook's confirmation receipt all go through. `tests/booking/when-label.test.ts` has no surcharge case, so nothing fails.

**This plan composes with 08-05's fix rather than reverting it.** 08-05 established the correct derivation — read the persisted `booking.full_day` (drizzle 0016), fall back for pre-0016 NULL rows to a **positive day-rate match**, never an inequality (`08-05-SUMMARY.md` deviation 7). This plan moves that same idiom into `when-label.ts` so the eighteen call sites inherit it, and makes `fullDay` a **required** input so `tsc` — not a reviewer — enumerates every call site that must supply it. The two inline fixes in `book/page.tsx` and `bookings/[id]/page.tsx` stay exactly as they are; they render their own time label and do not call this module.

Purpose: the invite page, the RSVP emails and the organizer surface must state the session an attendee is actually being invited to.
Output: one corrected formatter, one new regression case, and every call site supplying the persisted snapshot.
</objective>
