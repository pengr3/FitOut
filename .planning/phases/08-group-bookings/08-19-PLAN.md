This plan adds one read primitive (`getCheckoutSession`) and one gated, database-free test that:
1. proves two byte-identical POSTs mint two different payable session ids (the falsification that justifies 08-18's expire-before-create) — **Gap A's real-API proof**;
2. proves `expireCheckoutSession` actually retires a session at the provider — **Gap A's guard, proven**;
3. proves the re-price supersession end to end — an expired-then-replaced session is expired at the provider while its replacement is active — **Gap B / CR-02's live assertion**;

The test's PRIMARY gate is an explicit opt-in env var `RUN_LIVE_PAYMONGO_PROBE=1` — NOT the secret-key prefix. It makes **zero** DB calls and expires every session it creates so no live payable session leaks.
