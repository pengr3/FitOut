```typescript
export function SpotsLeftChip({ state, remaining }: { state: SpotsState; remaining: number }): ReactElement;
```
Header comment, adapted from `headcount-meter.tsx:48-53`: **`state` is decided SERVER-SIDE** from
`lowStockThreshold(cap)` and passed straight through. This component MUST NOT re-derive it, MUST NOT import
`OPEN_LOW_STOCK_MAX`, and MUST NOT compare `remaining` to any literal — the threshold is a non-public server
constant, so a browser-side copy would silently disagree with the server (the D-75 `serviceFeeBps` trap,
`availability-calendar.tsx:235-242`). Scarcity is a fact about the CLAIM; only the claim's own basis can
decide it.

The three states, exactly:

| `state` | copy | treatment | non-color signal |
|---|---|---|---|
| `open` | `Spots available` | `Badge variant="secondary"` + lucide `UsersRound`, muted | the word "available"; **NO number** |
| `low` | `Only {remaining} left` | `border-brand/30 bg-brand/10 text-foreground`, coral `UsersRound`, text 14/600, `tabular-nums` on the numeral | the exact numeral in the text |
| `full` | `Fully booked` | `Badge variant="secondary"` + `text-muted-foreground` + lucide `CalendarX2` | the words |

Rules, all binding:
- `Only 1 left` is the SINGULAR of the same string — no separate copy, no "Last one!".
- Wrap in a container with `role="status"` so a date change is announced (mirrors `slot-picker.tsx:242-244`).
- The chip is **never focusable and never clickable** — no `button`, no `onClick`, no `tabIndex`.
- **No `--destructive` anywhere**, no red, no amber, no new token. `full` is a normal state.
- **OC-14: there is no waitlist in v1** (DISC-02 stays deferred). The `full` state must therefore offer NO
  "Notify me", "Join the waitlist" or "Get alerted" affordance — its next step is another day, and the day
  panel supplies that sentence. Never advertise a mechanism that does not exist.
- The number appears ONLY in the `low` state (O4). Never `Almost gone!`, `Selling fast`, or any invented
  pressure — the backend supplies only `{remaining, cap}` and cannot substantiate more.
