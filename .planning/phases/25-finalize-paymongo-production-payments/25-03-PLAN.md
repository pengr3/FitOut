## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| PayMongo provider delivery → payment webhook | Untrusted network input becomes payment state only after raw-body HMAC, dedupe, and the single status-scoped writer. |
| PayMongo provider API → reconciliation job | A server-side probe can recover missed delivery but must not invent paid state from browser behavior. |
| controlled transaction → refund/manual-return operation | A real-money exception needs an accountable path for each enabled rail. |
