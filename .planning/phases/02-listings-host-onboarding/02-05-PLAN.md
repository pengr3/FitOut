<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| anonymous public → listing data | The page is intentionally unauthenticated; it must expose ONLY published listings and ONLY public fields |
| stored exact address → public projection | Exact street + exact coordinates must not leak before the host opts in (or, future, before a confirmed booking) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-PII | Information Disclosure | exact street address / exact coordinates | mitigate | publicListing allow-list drops addressLine1/addressLine2/postalCode and fuzzes coordinates unless showExactAddress (D-09); map renders a fuzzed circle in approximate mode (D-11). |
| T-05-NONPUB | Information Disclosure | draft/unlisted listings | mitigate | RSC 404s when status !== "published"; e2e asserts draft/unlisted are not publicly viewable (D-13). |
| T-05-BOOKABLE | Spoofing (false affordance) | book CTA | mitigate | CTA is derived from deriveBookable (status + emailVerified + payoutsEnabled), never from status alone (Pitfall 4); disabled when not payable. |
| T-05-OWNERLEAK | Information Disclosure | host info on the page | mitigate | Reuse publicProfile() for any host info shown (no private fields). |
</threat_model>
