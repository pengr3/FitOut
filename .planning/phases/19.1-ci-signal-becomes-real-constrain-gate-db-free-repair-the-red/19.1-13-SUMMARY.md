## The flake that was not a flake

The plan instructed: *"the zero-height measurement case is a measurement taken before layout settled. Add a settle in the established shape."* That instruction came from `19.1-RESEARCH.md`'s reading — *"a 0px measurement means the element was measured before layout; likely a missing settle."*

The settle was added in exactly the prescribed shape — `toBeVisible()`, which is Playwright's own definition of a non-empty bounding box, asserting the precondition the measurement depends on rather than widening a timeout. **What it printed refuted the hypothesis it was added for:**

```
strict mode violation: getByTestId('confirmation-moment') resolved to 2 elements:
  1) <section data-testid="confirmation-moment" …> aka getByRole('main').getByTestId('confirmation-moment')
  2) <section data-testid="confirmation-moment" …> aka getByTestId('confirmation-moment').nth(1)
  - locator resolved to <section …>   - unexpected value "hidden"
```

There are **two** of the section and one is **hidden**. `boxOf` uses `document.querySelector`, which takes the first match — so every earlier *"0px tall"* was the box of the **wrong section**, not an unsettled box of the right one. `toHaveCount(1)` two statements earlier passes, so the second copy appears *between* the assertions: an overlap during the route's own streaming.

**It reproduces off CI, which the 0px reading never did.** Cold `.next` per the harness: `1 flaky, 3 passed (52.7s)`, attempt 1 failing with the identical violation. Against a `.next` dirtied by a production build: all three attempts, two viewports, both themes. Intermittent at rest, deterministic under compile pressure — which is why CI had only ever seen it as flaky, and why it is now a hard failure on a 2-core runner.

**The settle stays and the locator is deliberately not scoped to `main`.** Scoping it turns the suite green and deletes the only instrument that has ever named this defect — and the identical in-`main`/not-in-`main` signature is live at `avatar-crop.spec.ts:162`. The docblock was rewritten to state the refuted hypothesis, the real measurement and that prohibition, because 19.1-11 already had to repair one spec whose message asserted a cause the codebase had measured false.
