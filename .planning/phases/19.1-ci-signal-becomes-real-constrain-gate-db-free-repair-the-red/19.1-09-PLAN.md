<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| a declared shape constant → the layout it describes | The constant is a record of a measurement; once it stops describing the layout, it is either a regression signal or a stale record, and only a reproduction distinguishes them. |
| the When column's composed content → the Space column's residual width | Content added to one cell silently changes the space available to the one beside it. |
| the spec's own repair instruction → an executor under time pressure | "Re-measure and move the constant" is correct guidance that becomes a defect-blessing instruction if the reproduction is skipped. |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
