only then regenerate the committed reference set on the sanctioned Linux path.

push trains everyone to ignore red — the exact habit SC4 exists to break. And D-04 attaches a hard
condition: a regenerated diff that is a real regression is fixed, not blessed.

reference set produced only on the sanctioned path, and a verifying run showing the visual job green.
