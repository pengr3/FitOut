### A. Watch it red before you trust it green — evidence artefacts
**Source:** `.planning/phases/19-host-listing-surfaces-gates-that-actually-run/evidence/guards-pre-fix.txt`
and `guards-post-fix.txt` (both tracked).
**Apply to:** every SC1/SC2/SC3 predicate, and every repaired spec.

The convention is a **raw captured console transcript**, not prose — the file opens with the literal
runner output, environment banners included:
```
[playwright] project "visual" is NOT collected on win32: baselines are generated and compared ONLY in
mcr.microsoft.com/playwright:v1.60.0-noble (D-27/D-29); …
Running 3 tests using 3 workers
```
Three steps per predicate: (1) mutate the **tracked** file, run the checker, capture GREEN + exit 0 →
`guards-pre-fix.txt`; (2) fix the predicate, same mutation, capture RED with the `FAIL` line naming the
invariant → `guards-post-fix.txt`; (3) revert and prove it — `md5sum` before/after plus
`git status --porcelain` in the same file.
