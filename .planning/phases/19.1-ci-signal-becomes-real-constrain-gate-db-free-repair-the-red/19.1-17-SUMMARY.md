## Where the second copy came from, in the ancestor walk's own terms

    match 1 :  section/input → … → MAIN            → div.flex → body → html
    match 2 :  section/input → … → DIV#S:1[hidden]            → body → html

`div#S:1[hidden]` is where React writes content for a Suspense boundary that resolved after the shell
was flushed; an inline script commits it into the boundary and drops the div. Both routes carry a
`loading.tsx`, which is the boundary. The two chains are byte-identical below the divergence point.

**The window is named, not guessed.** The count runs 0 → 1 → 2 → 1. `toHaveCount(1)` retries until it
sees ONE, and one is exactly what the document holds while the staged copy is present and the
committed one is not; two statements later the commit lands with the staging div not yet dropped and
strict mode reports both. The window is between the flush and the commit, not between two renders.

## The repair on each, and what was rejected

| surface | repair | site |
|---|---|---|
| confirmation | `expectStreamCommitted(page, testId, where)` before the count assertion | `e2e/confirmation-decay.spec.ts` |
| profile | `expectPickerCommitted(page)` inside `pick()`, before `setInputFiles` | `e2e/avatar-crop.spec.ts` |

Both poll a CLASSIFICATION — a match with a `[hidden]` ancestor is staged, one without is committed,
and the precondition is *zero staged, at least one committed* — on the default expect budget. `>= 1`
committed deliberately, so the exactness stays with `toHaveCount(1)` / strict mode.

**Rejected, each with the constraint that decided it:** scoping the locator to `main` (prohibited at
the site, and it would hide a genuine copy delivered outside the landmark forever); handing `boxOf` the
visible match (same prohibition); widening a budget (forbidden, and it would not work — the count is
ONE during the window, so a longer wait returns sooner); `waitForTimeout` past the window (a sleep that
outlasts the commit outlasts a genuine duplicate too — this is what the second control forbids);
changing the route's streaming structure (production source, no measured product defect to justify it).
