## The CAVEAT, restated for plan 13

**What an allowlist entry reveals, and what it still hides — both measured, neither assumed.**

- An **expected** failure does **not** stop the remainder of its `describe.serial` group (19.1-02, `evidence/testfail-behaviour.txt` Q3: `x serial 1 / ok serial 2 / ok serial 3`, no "did not run" bucket). The allowlist is not hiding a tail it fails to declare.
- A **genuine** failure **does** stop the group, and 19.1-11 measured that directly on this file: `tabular-figures`'s grove case reported `1 did not run` before the annotation and **ran and passed** after it. On this file the annotation *reveals* a measurement the red was hiding.
- **What an entry does hide is narrower and is named at both call sites:** Playwright has no per-assertion expected failure, so on CI a break in any **other** clause of an annotated case is absorbed by its annotation. For `tabular-figures` that is clauses (a) and (b) — TRUST-02's own property — which still run and still assert unannotated on every developer machine and are green on both rasterisers today. **Read the allowlist as covering CASES, not assertions.**
- **A stale entry is more expensive than no entry.** An unexpected pass fails the run by name *and* consumes all three retries (19.1-02 Q2). An expected failure runs once (Q1).

## Decisions Made

- **The plan's two branches both miss, and plan 02 said so before this plan started.** The fixed-advance-width spec is not stale (it passes locally at 0px spread) and its finding is not open (`13-16-SUMMARY.md:356` records A1 settled green, "No Phase-17 finding to hand forward"). The third route — reproduce in the container, annotate with the real reason — is the one taken.
- **The mechanism is measured only as far as the measurement goes.** The container applies `font-variant-numeric` (the per-digit delta drops from 5.90px to 1.00px) and still does not equalise. That the difference is the *renderer* is proved by the single-dev-server setup; the internal font-stack path is **not** claimed anywhere in the reason string or the spec message. `document.fonts.check()` returned `false` in *both* environments, so it separates nothing and was excluded as evidence.
- **`test.skip` is not an entry** — this repository uses it for unreachable fixture rows that throw their own reasons — **except on the forbidden files**, where all three forms are caught because D-01 names each of them.
- **The pinned number is cross-checked against a paths constant**, so the docblock naming the entries and the number asserting them cannot drift apart silently.
