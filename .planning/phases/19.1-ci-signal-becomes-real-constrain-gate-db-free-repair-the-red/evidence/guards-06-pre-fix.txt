GUARDS — PLAN 19.1-06, PRE-FIX MEASUREMENTS
===========================================

WHAT THIS FILE IS. Every mutation below was applied BY HAND to the TRACKED
`.github/workflows/ci.yml`, the SHIPPED `scripts/verify-workflows.mjs` was run against it, and the
result was captured verbatim. Then the file was reverted and the revert was PROVED — md5 before and
after, plus `git status --porcelain`. A mutation is a measurement, and a measurement left in the tree
is a defect.

WHY IT EXISTS. This plan's subject is the axis-versus-property error: a predicate that asserts a
key's PRESENCE without denying the modifiers that neuter it, or that LOCATES its subject by a
substring of a `run:` body. Both classes are invisible to a reading of the code — plan 19.1-05
demonstrated that by loosening the checker's own conjunct at `:982` and watching the standing suite
report 16 of 16 GREEN. So each site is MEASURED before it is repaired, and a site whose vector does
not reproduce is recorded as refuted rather than repaired on suspicion.

ELISION RULE, STATED SO AN OMISSION CANNOT BE MISTAKEN FOR A SELECTION. The checker closes each
section with a `parsed values` block — four-space-indented lowercase key lines dumping the whole
parsed tree. Those lines are IDENTICAL in every capture except where a mutation changed the value
they print, and they are hundreds of columns wide. They are filtered out of every transcript below by
`grep -vE '^ {4}[a-z]'`. NOTHING ELSE IS REMOVED: every heading, every FAIL line, every summary line
and every exit code is verbatim.

THE THREE TRIGGER VECTORS (Task 1) COME FIRST, THEN THE TWO STEP-ANCHOR VECTORS (Task 2).
