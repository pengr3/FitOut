<objective>
Write the pure half of the week-at-a-glance: one function that returns, for each of seven days, the segments
to draw and the sentence to announce.

Purpose: D-153 makes the bars decoration and the text the meaning. The only way that claim survives a future
edit is for both halves to come out of the same call — a component that draws from one derivation and
announces from another is one refactor away from lying. Writing it as a pure, directive-free module also
makes it unit-testable in the node environment, which is where a seven-day table belongs.

Output: `deriveWeekStrip`, the shared on-the-hour label map, and a table-driven test that pins exact
rendered strings.
</objective>

    Create the module with NO directive, no database import and no clock read — the same three refusals
    `block-reason.ts` states in its own header, for the same reason: it must be importable by a client editor
    and unit-testable in node.

    Export the on-the-hour label map and the weekday labels from here so the editor's selects and the strip's
    sentences read from one source. The editor will be re-pointed at them in a later plan; this module is

    Export `deriveWeekStrip`, taking the array of weekly windows the editor holds and returning exactly seven
    entries, always, in Sunday-first order. Each entry carries its day index, its short day label, its
    segments (each an open hour and a close hour as integers), and its sentence.

    Sentence shapes, from the copy contract:
    - one window: the full day name, a colon, the open label, the word "to", the close label.
    - several windows: the same, with the ranges joined so the last is preceded by "and".
    - no windows: the full day name, a colon, and the closed word.

    Segments are sorted by open hour so the announced order and the drawn order agree. Windows that touch at
    an endpoint stay TWO segments — they will visually merge, and that is correct, because the space is open
    continuously across the boundary, which is what the half-open range convention means. Do not insert a
    forced gap and do not coalesce them into one segment, because the sentence must name what the host typed.

    Tolerate a malformed or partial window the way a live form emits one mid-edit (an undefined entry, a
    missing time): skip it rather than throwing. The form is the authority on validity and the shared schema
    is the authority on saving; this function's job is to keep drawing while the host types.

    Do not re-implement overlap detection. The editor already owns the client-side overlap math and the
    shared schema owns validation — a second check is GATE-NOREG 6.

    Write the header the way `block-reason.ts` writes its own: what the module is, why it is directive-free,
    and the rule that the bars and the sentence must come from one call.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| form state → preview | The preview reads live, unsaved, possibly-invalid form values; it must not throw and must not pretend they are saved |
| drawing → announcing | One derivation feeds both. A second derivation is a silent accessibility divergence |
| preview → validation | The shared schema and the editor's overlap math are the authorities; the preview adds neither |
