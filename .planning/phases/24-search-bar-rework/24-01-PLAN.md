## Trust Boundaries

| Boundary | Description |
|---|---|
| Browser interaction and URL to Server Component | Catalogue text, coordinates, label, and party size are attacker-controlled until server validation. |
| Server Component to database query | Only validated typed values may become parameter slots in the stage-one listing read. |
| Photon/browser geolocation to retained client answers | External resolver data and browser coordinates may be stale, denied, malformed, or spoofed and must not advance before a success callback. |
