# BLOCKING CONSTRAINTS — Read Before Anything Else

> These are not suggestions. Each constraint below was discovered through actual failure during Phase 7 execution.
> Acknowledge each one explicitly before proceeding.

- [ ] CONSTRAINT: **A green suite does not mean money moves** — Phase 7's cancellation refund path was structurally incapable of dispatching a refund while every related test passed. The at-most-once assertion passed *vacuously with zero calls*. Mitigation: for any money-movement path, assert a POSITIVE case (money actually moved, with the call captured) before trusting any at-most-once / guard-not-violated assertion.
- [ ] CONSTRAINT: **`db.execute()` returns `timestamptz` as Postgres TEXT** — an `as unknown as SomeRow[]` cast hides this from `tsc`, eslint AND `next build`; it crashes at runtime on the first real row. Mitigation: select strict ISO-8601 via `to_char` and hydrate once at the boundary, or use the shared `readDbNow()`. Never cast a raw timestamp row.
- [ ] CONSTRAINT: **A stale `public` schema is invisible to the test suite** — `tests/helpers/db.ts` replays migrations into isolated per-test schemas, so `public` can be several migrations behind while everything is green. Phase 6 verified green against a DB missing its own `booking_no_overlap` widening. Mitigation: run `npm run db:migrate` and confirm nothing pending BEFORE trusting any verification result.
- [ ] CONSTRAINT: **Security gates must be mutation-verified with a positive control** — 07-11's host owner-gate hole (a host could cancel another host's booking) was found ONLY because mutation testing was mandatory. A deny-everything implementation passes an owner-scope file that has no positive control. Mitigation: remove the predicate, confirm the test goes red, restore, confirm `git diff` is empty — and include a "the owner CAN still act" case.

**Do not proceed until all boxes are checked.**

## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| Vacuous money assertions | `tests/paymongo` asserted "createRefund called at most once" and passed with zero calls, because `booking.payment_method` did not exist and `isApiRefundable` fails closed. Every cancellation would have moved ₱0 while reporting success. | blocking | Every money path needs a positive-movement test that captures the actual provider call, not only an at-most-once bound. |
| Timestamp cast through `db.execute` | `as unknown as { now: Date }[]` on a `SELECT now()` compiles, lints and builds, then throws on `.getTime()` for the first real user. Hit independently in 07-06, 07-09 and 07-12. | blocking | Use `readDbNow()` / `to_char` + boundary hydration. Follow `src/lib/booking/bookings-query.ts`. |
| Stale `public` schema | Isolated per-test schemas mask an unmigrated `public`. Migrations 0010–0012 sat unapplied through all of Phase 6's verification. | blocking | `npm run db:migrate` + pending-check before any phase verification is trusted. |
| Unverified owner gates | Host ownership lives on the *listing*, so it cannot be a bare column predicate the way `booker_id` can. The plan's SQL simply omitted the equivalent scope. | blocking | Mutation-verify every owner-scope test, always with a positive control. |
| Trusting plan text and research as fact | 07-04's plan contained three money bugs; 07-12's D-97 guard matched no production row; 07-13's no-send guard fired immediately instead of never — an error shared by the plan, 07-RESEARCH Pitfall 9 AND the orchestrator's brief. | advisory | Probe the live DB / write the failing case first. Treat acceptance criteria as claims to test, not truths. |
| Acceptance greps disarmed by mandated comments | Many plans mandate a header comment containing the very literal a `grep -c ... == 0` criterion forbids, making the grep unfalsifiable. Recurred in 07-02, 07-03, 07-07, 07-13, 07-15. | advisory | Reword the comment so the grep stays genuinely fallible; document rather than game. |
| Re-deriving `fullDay` from `total !== rate × hours` | Broke the moment `quoted_total_cents` became all-in (D-74) — every hourly booking would have rendered "Full day" across both dashboards, both detail pages and every lifecycle email. Caught three separate times. | advisory | Use `spacePriceCents`; `WhenLabelInput.spacePriceCents` is now required so `tsc` finds every call site. |
