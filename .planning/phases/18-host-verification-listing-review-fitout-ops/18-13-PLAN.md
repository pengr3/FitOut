<objective>
Tell the host what happened on the surfaces they already visit — and offer a way out only where one
actually exists.

Purpose: D-230 and the read half of OPS-05. A rejection the host cannot read is not a decision, it is
a disappearance. But this project's own rule is that a signal names the state, the reason AND the way
out, and two of the four states here have no way out: `pending` (there is nothing the host can do) and
`suspended` (appeals are out of scope). Where there is no way out, saying so plainly beats inventing a
control that acts on nothing.

Output: one signal module of named copy constants, one extended chip function, two host surfaces, and
a test that pins both the sentences that must appear and the ones that must not.
</objective>
