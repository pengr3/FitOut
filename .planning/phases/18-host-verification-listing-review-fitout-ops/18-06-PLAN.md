<objective>
Make approval something a host can lose, and make rejection something a host can recover from.

Purpose: Success Criterion 4 — a material edit to an approved listing returns it to review. Two things
make this harder than it reads. First, `draftSchema` has no photos field, so the site D-231 names
structurally cannot see a change to the single highest-signal fake-listing edit there is; the trigger
has to live in two places. Second, D-232 as written says nothing about `rejected`, which would leave a
rejected listing dead forever while the host surface offers an "Edit this listing" route that goes
nowhere — D-249 closes that, and it is resubmission, not appeal.

Output: one guarded flip helper, two detection sites each stating why there are two, and one test file
that covers all five material fields including photos.
</objective>
