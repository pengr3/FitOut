<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser → ops server action | Server Actions are reachable by POST regardless of what UI exists; Next's own docs say to treat them as public API endpoints |
| operator keyboard → durable column → host's inbox | The rejection reason is free text that becomes a stored value and an outbound email |
| ops action → `host_verification` / `listing.review_state` | The write that decides whether a space can be sold |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-18-0501 | Elevation | ops server action invoked directly, bypassing the UI | mitigate | Every exported action calls `requireStaff()` as its FIRST statement; grep-counted in the acceptance criteria and mutation-proved RED |
| T-18-0502 | Repudiation | a money-adjacent ops act with no attributable actor | mitigate | `recordAudit({ actorId: staff.id })` on both branches of every action; the test READS THE ROW BACK because `recordAudit` swallows its own insert failure |
| T-18-0503 | Tampering (stored XSS) | host-visible rejection reason | mitigate | Zod `z.enum` over a closed taxonomy plus a `.max(280)` note; stored as text; rendered as React text, never `dangerouslySetInnerHTML`; the email half rides the shipped escaping tests |
| T-18-0504 | Information disclosure | PII in `audit.meta` (D-72) | mitigate | `meta` carries ids and enum values only; the free-text note stays in the durable domain column. Asserted in `tests/ops/reject-reason.test.ts` |
| T-18-0505 | Denial of service | privileged-action flooding | mitigate | `rateLimit(\`ops-<verb>:${staff.id}\`, …)` keyed on the authenticated identity, never IP; the denial is itself audited |
| T-18-0506 | Elevation | fail-open on an unregistered verification provider | mitigate | `resolveVerificationProvider` returns `null` for anything unregistered, which resolves to NOT verified; mutation-proved RED |
| T-18-0507 | Information disclosure | a queue built on `audit` losing rows silently | mitigate | The queue reads domain tables only; grep-asserted. `recordAudit`'s swallow is deliberate on money paths and must never be depended on |
| T-18-0508 | Tampering | a stale decision applied twice (double-approve) | mitigate | Guards in the WHERE (`status IN ('pending','unverified')`); a 0-row result is a calm refusal, never a silent success |
| T-18-SC | Tampering | npm/pip/cargo installs | mitigate | No package installed. Explicitly NOT `npm install server-only` — Next aliases the specifier and installing it is a recorded-decision reversal |
