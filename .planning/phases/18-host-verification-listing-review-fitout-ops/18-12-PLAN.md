<objective>
Put the console on a route where a prober cannot tell it exists.

Purpose: OPS-02 says no ops power is reachable by a non-staff account or by knowing a URL, and that a
non-staff caller cannot distinguish an ops route from one that does not exist. Following D-216
literally and alone produces a response that FAILS that last clause by exactly one number: every
`/ops` page needs a build-mandated `loading.tsx`, whose Suspense boundary commits HTTP 200 before a
page-level `notFound()` can run — so a prober separates "exists but forbidden" from "does not exist"
with a single `curl`. The fix is already shipped on `/listings/[id]` and this plan reuses it.

Output: four route files, two measured design constants, three pinned inventories moved in the same
commit, one structural guard test, and three e2e rows.

⚠ The status-line PROOF is a production-build `curl` transcript and belongs to plan 18-14. No
automated instrument in this repo can read an HTTP status line.
</objective>
