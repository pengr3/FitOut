<objective>
Assemble the two booking pages and wire the listing CTA seam. The reserve page (`/listings/[id]/book`) reads the hold created by `placeHold` (owner-gated — it never creates the hold, avoiding GET-side-effect duplicates), shows the listing summary + selected window (venue-tz) + `PriceBreakdown` (frozen quote) + `HoldCountdown` + `Confirm`; an already-confirmed own hold revisited here redirects to the confirmation (D-42), not the expiry state. The listing "Book this space" CTA becomes a `<form action={placeHold}>` that places the hold on entering checkout (D-39); when sign-in is required it threads the selected window through the sign-in `callbackURL` so checkout resumes on return (D-41).

Output: `listings/[id]/book/page.tsx`, `bookings/[id]/page.tsx`, and the CTA wiring in `listings/[id]/page.tsx` (+ sign-in resume + DISPLAY_CURRENCY import swap).
</objective>
