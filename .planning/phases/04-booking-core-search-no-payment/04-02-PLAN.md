<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| URL searchParams → server | Every search param is attacker-controllable; validated by `searchParamsSchema` before any SQL |
| client booking selection → server | The picked window/idempotency key is untrusted; shape-validated by `bookingCreateSchema`, invariants re-derived later |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-ORIGIN | Tampering | searchParamsSchema lat/lng | mitigate | Bound lat∈[-90,90], lng∈[-180,180], radius∈{2,5,10,25}; `z.coerce.number` fails safeParse on NaN rather than throwing (Pitfall "Tampered search origin") |
| T-04-VOCAB | Tampering | type/activity/sort params | mitigate | `z.enum(spaceTypeValues)`/`z.enum(activityTagValues)`/`z.enum(["nearest","price"])` — only vocab keys reach the query builder |
| T-04-PRICEIN | Tampering | priceMax / page | mitigate | Int >= 0 bounds; negative/oversized values rejected by safeParse |
| T-04-SEEDID | Information disclosure | seed script on shared DB | accept | Seed uses namespaced `seed_*` ids and public listing data only; no PII, no secrets; idempotent cleanup |
| T-04-SC | Tampering | package installs | accept | No new runtime packages (RESEARCH Package Legitimacy Audit). If `tsx` is not already available, run it via `npx --no-install` or add as a devDependency behind the standard install; no third-party registry |
</threat_model>
