| Boundary | Description |
|----------|-------------|
| booker input → hold insert | The client-supplied window/price/idempotency is untrusted; the server re-derives price and relies on the DB constraint for occupancy |
| concurrent connections → booking table | Two racing bookers cross here; the EXCLUDE constraint (not app code) is the sole arbiter |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-DOUBLEBOOK | Tampering | createPendingHold insert | mitigate | The `booking_no_overlap` GiST EXCLUDE constraint is the SOLE authority; the find-free probe is advisory; loser 23P01/40P01 → "just taken" (never a query-then-insert guard) |
| T-04-PRICETAMPER | Tampering | quotedTotalCents | mitigate | `quoteWindow` re-derives hours/price server-side and freezes the snapshot; the client RailSelectionSummary figure is display-only (Pattern 4, CLAUDE.md) |
| T-04-IDEMCONFLATE | Tampering | 23P01 vs own-hold/23505 | mitigate | Own-hold pre-check + 23505 backstop return the SAME booking; ONLY 23P01/40P01/exhaustion map to "just taken" (Pitfall 6, the D-42 failure) |
| T-04-TXABORT | Denial of Service | savepoint-less outer tx | mitigate | Per-unit `tx.transaction` SAVEPOINT so a 23P01 rolls back only that attempt (no 25P02 → raw 500); outer loop retries 40P01 |
