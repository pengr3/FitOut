<objective>
Close **F11 / D-260**: a suspended host's `/host/earnings` names the frozen session.

Phase 18-07's payout freeze is **pre-claim** — a suspended host's due payouts are filtered out
*before* a `host_payout_ledger` row is written, so a delivered session produces **no payout line at
all**. The host watches money stop, on the page where they would look for it, with nothing anywhere
that says why. `HostingPausedNotice` already renders there and already says *"payouts are on hold"*
generically. D-260 asks for the specific: **which** session.

Purpose: the one place a suspended host looks for money now tells them what is missing and why,
without promising anything about getting it back.
Output: one new server module, one sentence in the copy owner, one optional prop, one wired page.
</objective>
