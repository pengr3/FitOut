## Decisions Made

- **Seven, in the ROADMAP's order plus the two appended.** `title` before `description`, after `price`, matching the plan and the test's set-equality assertion.
- **One detection site, deliberately.** The research's point is the load-bearing one: photos need two sites because `draftSchema` cannot see them; title and description need one because it can. Adding a second site for fields the first can already see would be the T-18.1-0302 threat (a re-review path a code path can forget) volunteered for free.
- **The softening ban is written down, not assumed.** The single most likely future "fix" to this code is a trivial-edit escape hatch — a minimum diff length, a whitespace-only check, a "did the meaning change" heuristic. Each is the "material but still sellable" variant the PM rejected. The detection site now names all three and refuses them, because the next person to feel this cost will feel it as a bug report.
- **The inverted case moved describes.** Keeping it under `NEGATIVES` would have kept the diff smaller and the test output wrong. The record of its inversion travels with it, so nothing is lost by moving it.
- **`MATERIAL_FIELDS` is a decision record, and this plan proved it rather than assuming it** (deviation 4).
