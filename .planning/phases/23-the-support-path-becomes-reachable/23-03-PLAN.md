## Trust Boundaries

| Boundary | Description |
|---|---|
| Vercel DNS and deployment | Domain assignment and environment scope select production routing and sender authorization. |
| Resend sender verification | DNS grants an external service authority to send as FitOut. |

| Mailbox proof to planning evidence | Real messages prove reachability but can contain PII and bearer links. |
