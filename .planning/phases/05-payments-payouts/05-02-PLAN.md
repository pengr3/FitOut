Canonical request shapes (05-RESEARCH.md § Pattern 1 + Code Examples — CITED to docs.paymongo.com):
- Checkout: `POST /v1/checkout_sessions` body `{ data: { attributes: { line_items:[{amount, currency:"PHP", name, quantity:1}], payment_method_types:["card","gcash","paymaya","qrph"], reference_number, metadata, description, success_url, cancel_url, send_email_receipt:true }}}` → resp `data.id`, `data.attributes.checkout_url`, `data.attributes.payments[]`
- Batch transfer: `POST /v2/batch_transfers` body `{ transfers:[{ provider:"paymongo", amount, currency:"PHP", purpose, description, reference_number, source_account:{number,name,bic}, destination_account:{number,name,bic}, callback_url?, metadata }]}` → 201 `{ transfers:[{ id, status }] }`; PayMongo BIC = `PAEYPHM2XXX`
- Wallets: `GET /v2/wallets?status=activated` → `data[].account.account_number`, `data[].account.account_name`, `data[].status`
- Refund: `POST /v1/refunds` body `{ data:{ attributes:{ amount, payment_id, reason:"others", notes }}}`  ⚠ FAILS for QRPh/UBP (unsupported)
