<objective>
Regenerate the court baseline set in the pinned image, force the comparison run that a
`GITHUB_TOKEN` push does not trigger, and record its id as the phase's closing evidence.

Purpose: **[13-16]** measured a phase completing with `gate-visual` red and nothing noticing, which
is why 17-CONTEXT **D-202** names a *green comparison run on the phase's head commit* — not a
generation run — as the whole bar. And `baselines.yml`'s own header states the trap this plan exists
to avoid: its push authenticates with `GITHUB_TOKEN`, and a `GITHUB_TOKEN` push **triggers no
workflow run**, so regenerated PNGs have historically been written and never compared. The empty
commit or re-dispatch is a required step, not an optional one.

**This machine cannot do any of it locally, structurally.** `process.platform === "win32"`, so
`playwright.config.ts` does not construct the `visual` project at all and prints a warning saying so.
`npx playwright test --project=visual` cannot run here. Every GATE-01 clause in this plan is a CI
action driven through `gh`.

Sequencing: this plan runs **last**. A post-regeneration commit invalidates the evidence and forces a
re-run, so nothing may land after the comparison whose id is recorded.

Output: a regenerated court set, a read dispatch diff, and a recorded green comparison run id.
</objective>
