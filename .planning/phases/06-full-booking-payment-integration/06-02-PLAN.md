## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| application read predicates → occupancy truth | A read predicate that omits requested/approved shows a held slot as free → booker collides. |
| concurrent bookers → the same slot | Two racing inserts must not both win — the DB EXCLUDE, not app code, arbitrates. |
| in-tx sweep write-target ↔ SLA cron write-target | Both must map a lapsed `requested` row to the SAME terminal status (`declined`) or the terminal value depends on a race (Warning-1). |
