| client editor → server action | Client-side Zod is UX only; the server (Plan 03) is authoritative. |

| T-03-DESTRUCTIVE-UX | (usability/safety) | remove/unblock | accept→mitigate | All removals are reversible and use neutral styling with a confirm dialog; no hard-destructive action exists in this phase (UI-SPEC). |
</threat_model>
