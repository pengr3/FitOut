=== B. THE STATEMENT, RUN IN A TRANSACTION WITH A ROW-COUNT GATE ===

  BEGIN;
  DO $$
  DECLARE n integer;
  BEGIN
    DELETE FROM listing
     WHERE host_id = 'AcW4AhUfkMexEvvEUa8KjsngD7ubMoZy'
       AND deleted_at IS NULL
       AND created_at BETWEEN '2026-09-03 10:51:56Z' AND '2026-09-03 10:52:40Z';
    GET DIAGNOSTICS n = ROW_COUNT;
    RAISE NOTICE 'D-01 affected_rows=%', n;
    IF n <> 4 THEN
      RAISE EXCEPTION 'AFFECTED ROW COUNT % IS NOT 4 - ROLLING BACK', n;
    END IF;
  END $$;
  COMMIT;

The gate is not decoration. Any count other than 4 raises, which aborts the
transaction, which turns the COMMIT into a rollback — the delete could not have
partially applied. The window literals are UTC and byte-identical to Task 2's,
because `listing.created_at` is `timestamptz`.

    NOTICE:  D-01 affected_rows=4
    DO
    COMMIT
