<objective>
Give the silent bounce a sentence.

Today a failed creation returns the host to their grid carrying no message at all — a blind spot
already recorded in `18.1-UI-SPEC § NOT COVERED`. This closes it, following the project's own rule
that a signal names the state, the reason and the way out.

Purpose: with the verification redirect sitting in front of it, this branch now catches genuine
infrastructure failure only. That makes the copy easy to get wrong in one specific way — a sentence
implying a verification problem sends the host to a page where nothing is wrong, which is the
copy-about-a-check-that-never-ran defect one route over.
Output: a copy module, a query string on an unchanged destination literal, and an inline muted notice
that renders in both grid states.
</objective>
