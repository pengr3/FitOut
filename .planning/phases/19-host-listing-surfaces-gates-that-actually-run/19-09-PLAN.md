<objective>
Close GAP 1: the D-02 reuse predicate has a reachable hole, and the method that was supposed to
find it cannot.

`createDraftListing` decides "is this draft untouched?" with a `NOT EXISTS` set covering
`listing_photo` and `operating_hours`. `addBlock` (`src/app/actions/blocks.ts`) inserts an
`availability_block` row and never touches the parent `listing` row, so it bumps no `updated_at`
and is invisible to the predicate's staleness term. A host who creates a draft, blocks a date on it
from the shipped Availability page — two clicks from the grid — and then presses *Create listing*
again silently receives listing #1 back, with the blocked dates inherited into what they believe is
a brand-new listing.

Purpose: this is the THIRD instance of one class, and both previous fixes closed an instance rather
than the class. The deliverable is therefore not the third conjunct. It is a standing check that
answers "how would a FOURTH child table be caught?" — the census method, not the census output.

Output: the third `NOT EXISTS` conjunct, a fourth D-02 case that watches it go red then green, a
build-blocking design test that enumerates every child of `listing` and requires each to be covered
or exempted with a reason, and a docblock whose stated verification method can see raw SQL.
</objective>
