<objective>
Close CI-01 by proving the gate can go red, measuring what it costs, and only then making it block.

Plan 19-01 shipped the job. This plan turns it from a job that reports into a gate that stops
things — in the order D-15 requires, because a gate that reports but cannot block is the shape D-24
already left this project with, and a gate nobody has seen fail is a rubber stamp.

Purpose: success criterion 4 says "proven by watching one fail, not by reading the workflow file".
This plan is that proof, plus D-13's measurement, plus the record of a repository setting that no
file in the repo can carry.
Output: a measured wall-clock, two watched reds, and a required check with its provenance written
down.
</objective>
