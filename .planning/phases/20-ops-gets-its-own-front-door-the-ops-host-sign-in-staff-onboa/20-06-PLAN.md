<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Browser -> Server Function | Untrusted form fields and bound lifecycle versions reach callable POST endpoints. |
| Bearer URL -> Server Component | A possibly malformed or scanner-fetched credential reaches read-only inspection. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-20-06-01 | Spoofing | operator lifecycle functions | high | mitigate | Call `requireStaff()` first and derive actor id only from the returned session. |
| T-20-06-02 | Elevation of Privilege | resend/cancel target | high | mitigate | Bind current invitation id/version server-side; reject client actor/email/alternate target fields. |
| T-20-06-03 | Tampering | GET/link scanner | high | mitigate | Server Component invokes inspection only; mutation is exclusive to POST acceptance. |
| T-20-06-04 | Information Disclosure | inactive invite route | medium | mitigate | Collapse all inactive token classes to one structure/copy without email or classification. |
| T-20-06-05 | Information Disclosure | action diagnostics | medium | mitigate | Return typed nonsecret outcomes and exclude token/email/password from logs and audit payloads. |
| T-20-06-SC | Tampering | package installs | high | mitigate | No dependency install; use the repository's installed Next.js and test interfaces. |
</threat_model>
