<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Ops shell -> auth sign-out | Current session is destroyed before navigation. |
| Marketplace <-> ops navigation | Absolute links cross distinct origins and cookie jars. |
| Runtime error -> user-visible recovery | Internal route/stack/account state could leak into the UI. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-20-08-01 | Spoofing | cross-host links | high | mitigate | Resolve both destinations from configured exact origins, never request headers. |
| T-20-08-02 | Elevation of Privilege | post-sign-out cookie | high | mitigate | Destroy Better Auth session and E2E-test immediate `/ops` refusal. |
| T-20-08-03 | Information Disclosure | ops error shell | medium | mitigate | Render neutral recovery without route, stack, account, or authorization detail. |
| T-20-08-04 | Open Redirect | sign-out/cross-host navigation | high | mitigate | Use fixed configured origins and fixed same-host path; accept no callback for sign-out. |
| T-20-08-05 | Information Disclosure | cross-host exit query | medium | mitigate | Append no token/callback/account/cookie data and assert clean URLs in E2E. |
| T-20-08-SC | Tampering | package installs | high | mitigate | Use existing auth, UI, Playwright, and Vitest dependencies only. |
</threat_model>
