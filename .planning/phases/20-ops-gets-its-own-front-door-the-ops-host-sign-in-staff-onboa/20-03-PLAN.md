<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| browser origin/cookies → Better Auth | Host, Origin, callback, and cookies are untrusted request data |
| credentials → staff role read | Valid credentials alone do not authorize ops access |
| reset email → browser | Absolute reset URL must remain inside the trusted ops origin |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-20-08 | Spoofing | dynamic auth base URL | high | mitigate | Exact allowed hosts/fallback and direct-call request headers; no attacker Host URL minting. |
| T-20-09 | Elevation of Privilege | cross-host session bleed | high | mitigate | Host-only cookies, no cross-subdomain setting, two-jar tests, post-login positive staff read. |
| T-20-10 | Spoofing | callback open redirect | high | mitigate | Parse/recheck exact origin and allow only `/ops` descendants. |
| T-20-11 | Elevation of Privilege | revoked-role cookie-cache survival | high | mitigate | Keep cookie cache disabled and test grant→revoke→next request. |
| T-20-12 | Information Disclosure | nonstaff/recovery response | medium | mitigate | Fixed nonstaff copy and enumeration-safe recovery result with immediate session cleanup. |
</threat_model>
