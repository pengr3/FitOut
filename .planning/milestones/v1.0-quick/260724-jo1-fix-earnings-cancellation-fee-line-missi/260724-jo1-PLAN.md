<objective>
Fix Phase-7 UAT gap G1: the `/host/earnings` unrecovered-cancellation-fee line renders
`You have ₱300.00in cancellation fees still to be deducted.` — with NO space between the
amount and "in". The source at `src/app/(host)/host/earnings/page.tsx:169` DOES contain the
space (`{formatMoney(...)}` + ` ` + `in`), but SWC's JSX whitespace transform strips the
leading space of the JSXText node that follows the `{formatMoney(...)}` expression container,
so the compiled/rendered output drops it (raw HTML: `₱300.00<!-- -->in cancellation fees`).

A pure-function/string test on `formatMoney` CANNOT catch this — the defect only manifests in
the compiled JSX render. The regression MUST render the fragment.
</objective>
