<objective>
Build the dashboard's two new blocks as components with their own hooks, so the page that composes them next
is a composition and not an invention.

Purpose: D-140 replaces a counts-and-links tile grid with today's real sessions, because a host with three
sessions today must be able to see who is coming without a second click — the only reading of HFLOW-03's own
success criterion a tile grid does not satisfy. D-142 makes a quiet day useful instead of empty. Both need
three carefully distinguished states, and this repository has recorded a dozen times that "the agenda
renders" is an assertion an ABSENT section can satisfy — so the container hook is present in all three states
and the states are told apart by their contents.

Output: an agenda component with four declared hooks, a signals component with one, a shared copy module for
the requests signal, and a jsdom test that walks all three states.
</objective>

|----------|-------------|
| server props → presentational component | Everything the agenda renders was formatted server-side; the component reads no clock, does no money arithmetic and formats no date |
| booker identity → host surface | Only a first name crosses, with a withheld fallback. No email, no surname, no phone |
| absence → failure | An empty agenda is a normal state of a working marketplace; dressing it as an error is a truthfulness defect |
| declared hook → rendered hook | The selector contract is a closed set asserted in both directions |
