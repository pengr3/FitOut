<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| loading plate → the arriving list | A plate that draws a third of the height it promises is a layout shift, which is the failure the loading-state family exists to remove |
| declared constant → skeleton file | A skeleton may only carry a value from the measurements inventory; a literal, or the constant's value re-typed, has been caught before |
| measurement → committed number | A number in prose drifts silently; a number in a test fails visibly |

| T-14-15-LITERAL | Tampering | the skeleton inventory | mitigate | Heights are declared constants with derivations; the skeleton gate is re-run and a literal grep is an acceptance criterion |
