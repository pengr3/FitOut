<objective>
Put the shared host measurements in one place, teach the row skeleton a second declared height, and spend
HFLOW-05 — the token pass that is allowed to change nothing else — behind a gate that proves it.

Purpose: six copies of one shell string and three near-twins of another are the reason a loading plate and
its page can silently disagree about the box they draw. Every later plan in this phase imports those two
constants, so they land first. HFLOW-05 rides along because it is the smallest, most tightly bounded change
in the phase and it needs exactly the constants this plan creates — and because the gate that freezes it
(`earnings-freeze`) must be authored against the SHIPPED file, green, before a single token moves.

Output: six declared constants with their derivations, a skeleton that can be told a height without a
literal, an AST freeze gate, and an earnings surface whose diff is provably tokens only.
</objective>
