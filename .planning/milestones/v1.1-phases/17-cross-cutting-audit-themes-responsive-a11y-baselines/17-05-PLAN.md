<objective>
Take the two mechanical conformance fixes the earlier phases routed here by name: **DS-09's adoption
gap**, and **[16-D7]'s slider** under 17-CONTEXT **D-197**.

Purpose: `tests/design/brand-recipe.test.ts:721` ships a measurement whose own docblock names this
phase as its owner and warns about exactly the shape it has become — *"a ceiling that reads as a
considered decision and is a forgotten one"*. The literal is `6`; the measured count today is **5**,
so the gate passes with a gap and would keep passing if a sixth appeared. And the zoom slider renders
`role="slider" data-disabled=""` with no `aria-disabled`, which is SC 4.1.2's *Value* clause on a
shipped control — `toBeDisabled()` reads `aria-disabled` on a non-native control, so the shipped e2e
assertions had to read `data-disabled` and say so in a comment that this fix invalidates.

**Ordering note for the phase:** DS-09's conversion adds +12px of horizontal padding on
`search-bar.tsx` (`size:default` is `px-2.5`, `size:touch` is `px-4`), which is a real layout change
at 320px and will move committed baselines. Landing it in wave 1 is deliberate: every later 320px
sweep then measures post-conversion code, and the predicted PNG list is written down before the
dispatch so that diff is read rather than accepted.

Output: five conversions, one flipped ceiling, one vendored attribute, two flipped assertions, three
rewritten comments.
</objective>
