rendered copy rather than inferred* — its errors are caught by **`src/app/error.tsx`, the root

path** is inside `src/app/(app)/`. Four files, one per group, each inheriting that group's real gates
— which is the point: the boundary that catches a throw is a property of the file path, and so is
the layout stack the booker actually sees.
