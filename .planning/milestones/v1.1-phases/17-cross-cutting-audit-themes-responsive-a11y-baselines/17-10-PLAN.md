<objective>
Close **[14-WR-03]**: the host routes' heading-order blindness, in the file that owns it.

Purpose: `e2e/host-headings.spec.ts` asserts exactly one `<h1>` per document across **28 states × 3
widths = 84 measurements**, and its own line 93 records what it cannot see — *"IT SAYS NOTHING ABOUT
`<h2>` AND BELOW. A surface whose sections skip from level one to level three has a broken outline and
passes this file completely."* That blindness is what let plans 14-12 and 14-13 promote two
`<h3>`-level advisories to `<h2>` on `/host/listings/{id}/availability` unobserved, while all 28
level-one assertions stayed green.

It cannot be inherited from axe. Under the declared conformance tags `heading-order` is
`best-practice`-tagged and does not run at all, so the UI-SPEC's sentence *"Axe's own `heading-order`
rule covers this on every other surface"* is false as written. Plan 17-07 enables the rule explicitly
in the one shared `.options()` object; that covers the axe sweep's route set. This plan covers the 28
host states, which the axe table may not carry because they need seeding. **They cover different route
sets and neither implies the other** — that is why both land.

Output: one new measurement inside an existing loop, red-watched against a skip.
</objective>

    same, go down by any amount, or go **up by at most one**. A jump from 1 to 3 is the failure. Note in
    the code that a DUPLICATE level is legal and is not what this asserts — that distinction is why the
    red-watch in Task 2 uses a skip.

    been measured, and an empty list satisfies a no-skip predicate perfectly. Assert a non-zero level
    count per state per width, with a message saying that number is what makes the clause below it mean
    anything.

    The failure message names the state, the width, the observed level sequence, and the specific
    transition that skipped — not "assertion failed". It must also forbid the easy fix: a broken outline
    is fixed by correcting the heading level (which the UI-SPEC's "may fix in place" table sanctions), not
    by removing the heading or by relaxing this assertion.
