Price rule that binds here too (D-75): the card shows a RATE, never a computed total. "₱450/hr" is a rate;

One clarification so a reviewer does not read a violation where there is none: satori sizes type with inline
style={{ fontSize: 64 }}. DS-13's arbitrary-size ban is `text-\[[0-9.]+px\]` — a TAILWIND CLASS pattern. An
inline numeric font size in an image renderer is outside it, and must be, because satori has no access to
the type tokens at all.

Fonts: satori requires at least one font buffer and next/font/google exposes none. Two Geist binaries
(Regular, SemiBold) are committed beside the route and loaded via fetch(new URL("./…", import.meta.url)).
NOT a D-127 violation: Geist is already the app's typeface, shipped by next/font; committing the same
family's binary for a renderer that cannot read CSS is not a new brand asset. Record the byte cost.

metadataBase resolves to http://localhost:3000 today (src/app/layout.tsx:52, DEFAULT_APP_URL), so og:image
will be a localhost-absolute URL until NEXT_PUBLIC_APP_URL is set. That is plan 11-14's second human_needed
item, not a bug in this plan.

⚠ Plan 11-01 guarded @/lib/booking/all-in-rate with `server-only`. The OG route is a Server Component, so
importing allInRateParts there is legal — confirm it, do not assume it.
