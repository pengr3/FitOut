<objective>
Mount the theme runtime: a `next-themes` provider on `data-theme` with a fixed `court` default, the real
FitOut identity metadata, the Sonner theme mapping, and both of D-08's override paths.

— which is why `src/components/ui/sonner.tsx:8` currently follows the OS colour scheme and renders dark
toasts inside a light-only app. And the Playwright seam this plan creates is what Phase 11's theme-swap
smoke and Phase 17's two-theme axe pass both depend on; it must exist and be documented here.

Output: the provider, the query-param affordance, the root layout mount and metadata, the fixed Sonner
mapping, the Playwright helper, and two green tests.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| URL query string → DOM attribute | `?theme=` is attacker-controllable input that reaches `documentElement`'s `data-theme` |
| localStorage → pre-paint script | `localStorage["theme"]` is read by next-themes before React hydrates |
| next-themes → document | The library injects an inline `dangerouslySetInnerHTML` script |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-10-02 | Tampering | `theme-query-param.tsx` | mitigate | The value is compared against the `THEMES` allowlist with `.includes()` and never cast with `as` and never interpolated; the effect returns early when `NODE_ENV === "production"`, a build-time constant the bundler prunes (ASVS V5). |
| T-10-05 | Tampering | next-themes inline script | accept | Vendor-controlled and static; nothing from the app is templated into it. Recorded for Phase 11's shell work: if a CSP is ever added, the provider needs the `nonce` prop (ASVS V14). |
| T-10-16 | Spoofing | `localStorage["theme"]` | accept | A presentation preference carrying no identity and granting no capability; it is not session state and is out of ASVS V3 scope. Documented in the provider header so a future reader does not mistake it for one. |
| T-10-17 | Elevation of privilege | root `ThemeProvider` mount | accept | The provider is a client component wrapping the tree; it receives no session, reads no server data, and moves no logic client-side (D-130 holds). |
</threat_model>
