<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser URL -> search RSC | `relax`, `radius`, `priceMax`, `page`, `date` are attacker-controllable and reach SQL predicates and a `::date` cast |
| relaxation outcome -> rendered claim | A band that names a constraint the query did not actually relax is a false statement about the booker's own search |
| ladder cost -> server load | Four extra queries on every zero-result search, each potentially carrying a full sequential Stage-2 loop |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-12-12-PARAMTAMPER | Tampering | the `relax` flag | mitigate | Parsed by `searchParamsSchema` as a bounded coerced int like every other param; a garbage value yields the default view and no throw, asserted |
| T-12-12-SQLI | Tampering | rung queries | mitigate | Every rung reuses `searchListings`' existing parameter-bound Drizzle `sql` templates and its `parsePickedDate` canonicalisation; no rung builds a predicate string |
| T-12-12-LADDERCOST | Denial of service | zero-result searches | mitigate | Sequential with stop-at-first-hit (never a fan-out), `page: 0`, a reduced `fetchLimit` bound, a hard cap of four rungs asserted by invocation count, and a declared 2000 ms budget with a two-rung fallback |
| T-12-12-FALSEBAND | Repudiation | band copy | mitigate | The band renders the rung the ladder actually returned; the e2e asserts the control's rendered value EQUALS the band's substring, both read from the DOM |
| T-12-12-CLIENTFILTER | Tampering | relaxation location | mitigate | The whole ladder runs server-side in the RSC; the client renders the outcome and never re-queries or re-ranks. `search-results.tsx` gains no filtering logic |
| T-12-12-UNDOLOOP | Denial of service | Undo | mitigate | `relax=0` makes Undo an addition rather than a removal, so the RSC does not re-relax; watched red by removing the flag |
| T-12-12-SC | Tampering | npm/registry installs | mitigate | Zero packages. `git diff --stat package.json` must be empty |
