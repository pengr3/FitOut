HOW THE COLLISION REACHES THE CLIENT TODAY, and none of it changes:

  placeHold -> createPendingHold -> INSERT inside a transaction
    -> 23P01 (exclusion violation) | 40P01 (deadlock) | NoUnitAvailableError
    -> mapBookingError -> a calm sentence
    -> PlaceHoldResult { ok:false, reason:"taken" | "sold-out", error }
    -> book-cta's branch

  ⚠ THE COLLISION UI IS A RENDERER OF THE CONSTRAINT'S RULING. It must never pre-check, never pre-filter,
  and never attempt to decide whether a slot is free before asking. The GiST EXCLUDE constraint inside a
  transaction is the sole arbiter (CLAUDE.md § What NOT to Use).

THE THREE CHANGES, in order of importance:

  1. REPLACE `router.refresh()` AS THE MECHANISM. Call `refreshDay()` from the hoisted provider (plan
     12-02) — which calls the already-public, read-only, Zod-validated `getDayAvailability(listingId,
     selectedDay)` — and set the notice in the SAME React commit, so the notice and the struck-through
     hours land together. `router.refresh()` MAY be kept in addition for the RSC-side facts, but it is not
     the mechanism: Next's own documentation says refresh merges the RSC payload "without losing unaffected
     client-side React (e.g. useState)", and the day's slots are exactly that state — seeded, moreover,
     for TODAY rather than for the selected day.
  2. NAME WHAT HAPPENED. The server sentence is generic and does not name the window. The client already
     holds the selection's start/end and the venue timezone, so it composes the named line itself.
     ⚠ THIS IS A DELIBERATE DEPARTURE from `book-cta`'s stated rule that the sentence comes from the
     server, and the departure must be RECORDED AT THE CALL SITE in those words: the server sentence is
     the RULING; the named window line is a RESTATEMENT OF THE BOOKER'S OWN SELECTION, not a second copy
     of a server decision. It must never leak `23P01`.
  3. DROP THE RAIL'S SELECTION AND ITS PRICE. Selection line becomes `No time selected`, the breakdown is
     removed, and the CTA reverts to disabled with the shipped hint.

| collision recovery -> availability read | The recovery must ride the existing public read model without widening it |
