WHAT ALREADY EXISTS AND MUST NOT BE RE-AUTHORED (`e2e/overflow-320.spec.ts`, module-local today):
  type FocusReading = { tag, label, inHeader, outlineStyle, outlineWidth, boxShadow }
  async function readFocus(page): Promise<FocusReading | null>
    — one `page.evaluate`; returns null for body/documentElement; `label` is
      `aria-label ?? textContent`, whitespace-collapsed, sliced to 40 chars.
  function expectRing(reading, where): void
    — the RENDERED focus criterion: `outlineStyle !== "none" && parseFloat(outlineWidth) > 0`
      OR `boxShadow !== "none" && boxShadow.trim() !== ""`. Its own docblock states why: Tailwind
      draws `ring-*` as a box-shadow, and a programmatic `.focus()` does not match `:focus-visible`
      in Chromium, so the walk must use real Tab presses.
  async function expectVisibleFocus(page, where): void — STAYS in overflow-320.spec.ts; it is
      coupled to that file's `inHeader` notion (the auth documents render no site header at all
      since D-162), and it is not what this walk needs.

by `overflow-320.spec.ts`. Use the same import, not a re-declared literal.
