<objective>
Ship the phase's one net-new route: an itemised booking record designed for a screen and for paper,
with the browser's own print dialog as the entire PDF pipeline.

Purpose: TRUST-05 asks that a booker can view and print an itemised receipt. D-74 chose a real URL over
a print stylesheet bolted onto the 688-line detail page, for two reasons: the detail page's cancel
buttons, trust block and status chrome all need suppressing, and there is no link to hand someone — and
Phase 15's confirmation email needs something to link to. D-75 draws the boundary that keeps this
honest: Philippine official receipts carry real legal requirements, and that is a business decision the
PM has not made, so the document must never imply it. 13-RESEARCH Pitfall 3 names the failure print
must prevent: `print-color-adjust`'s initial value is `economy` and Chrome's Background graphics box is
off by default, so any near-white ink on a filled surface prints invisible.

Output: the route, its skeleton, the itemisation, the print contract, the detail-page entry, and the
pinned counts moved in the same commit as the thing that moved them.
</objective>
